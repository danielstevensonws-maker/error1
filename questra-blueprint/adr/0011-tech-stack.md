# ADR-0011 — Tech stack
Accepted. TypeScript everywhere. Monorepo: npm workspaces (packages/contracts, packages/engine, packages/server, packages/web, packages/ai). Server: Node + Fastify; WebSockets via ws behind a thin transport interface. Database: Postgres (entities + append-only event table, indexed by session+seq); object storage + CDN for media; a Postgres-backed job queue (e.g. graphile-worker) for background jobs. Client: React + Vite + Tailwind; state via zustand + TanStack Query; Storybook against fixtures. Tests: vitest end to end; zod at every boundary. Hosting: any Node host for server+ws (e.g. Fly.io/Railway); web deployable to Vercel; keep vendor seams thin. Rejected: microservices (one team, one deployable), NoSQL primary (relational refs are the data model), serverless-only (persistent sockets).
